  # Hiruy Recipe Platform (React + Tailwind)

  A recipe app built with React, Vite and Tailwind CSS.

  ## Features
  - Recipe cards with a favorite button
  - Recipe detail view (ingredients and steps)
  - Add Recipe form (new recipes appear in the list)
  - Servings counter
  - Responsive layout (1 / 2 / 3 columns)

  ## Run it
  npm install
  npm run dev

  ## Built with
  React, Vite, Tailwind CSS, react-router-dom
